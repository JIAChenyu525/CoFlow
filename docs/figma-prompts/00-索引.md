# Figma AI 分步提示词索引

| 3 | 03-工作台.md | 核心页：项目工作台 | 最复杂，单独一步 |

| 9 | 09-状态补全.md | 空/加载/错误/只读 + 组件变体 | 收尾自检 |

## 用法要点

- 第 1 步只出方向，不出页面。选定后再进第 2 步，避免花色不统一。
- 如果 Figma 记不住上下文，每一步开头粘一句：「沿用前面已确认的视觉体系与组件库。」
- 第 3 步（工作台）是最难的一页，生成后先改它，改满意了再让后面的页面参考它。
- 每步生成后按「09-状态补全.md」里的清单自查一次。
